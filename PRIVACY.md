# Privacy Policy — ChatGPT RTL Fix

Last updated: October 9, 2026

ChatGPT RTL Fix processes visible text on `chatgpt.com` locally in the user's browser only to determine text direction (RTL or LTR) and apply presentation fixes.

## Data collection

The extension does not collect, transmit, sell, share, log, or retain personal data, conversation content, browsing history, identifiers, analytics, or telemetry.

## Network access

The extension makes no network requests.

## Storage

The extension does not use browser storage, cookies, IndexedDB, localStorage, or remote storage.

## Processing

Text direction detection is performed locally and transiently in the page's content-script context. Conversation text is not sent anywhere by the extension.

## Third parties

The extension contains no third-party libraries, trackers, analytics SDKs, advertisements, or remote code.

## Scope

The extension is designed to run only on `https://chatgpt.com/*`.

## Support and privacy questions

Open an issue in this repository if you have a privacy or support question. Please do not include private conversation content in reports.

## Disclaimer

This is an independent, unofficial extension and is not affiliated with or endorsed by OpenAI.
